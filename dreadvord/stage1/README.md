# DREADVORD — Stage 1 Prototype

This folder contains a modular, browser-playable Stage 1 prototype for DREADVORD built with Three.js and ES modules.

Run: open dreadvord/stage1/index.html in a modern browser (or serve with a static server). The prototype is optimized to run on mobile browsers; it uses procedural meshes and no external assets.

Included systems:
- Third-person movement and camera follow
- Touch joystick and action buttons (attack, dodge, guard, pause)
- Health and Stamina with regeneration and consumption
- Simple enemy AI with pursuit and melee attack
- Combat system (attack windows, damage)
- Objective and HUD
- Pause/resume overlay and local save scaffolding

Next steps: replace placeholder geometry with GLB models and add animations, polish audio and VFX, and extend combat and mission flow.
