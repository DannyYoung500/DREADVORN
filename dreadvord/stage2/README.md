# DREADVORD — Stage 2 Prototype

This Stage 2 build expands the gameplay loop with:
- Shadow Knight-style melee archetype in a small ruined-gate arena
- better melee combat loop and stamina handling
- enemy wave and arena pressure
- objective and HUD flow
- pause and resume flow
- save scaffolding for progression

Run:
- Open `dreadvord/stage2/index.html` in a modern browser, or serve the repo with a simple static server.

Notes:
- This is still a prototype, not a production game.
- The current placeholder characters are stylized mesh bodies and not production 3D art.
- The next step is replacing placeholder fighters with proper GLB animations and introducing the Fallen King boss arena.
