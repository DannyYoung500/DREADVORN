# DREADVORN
### When the world falls, the war begins.

DREADVORN is an in-development 3D zombie survival shooter planned for Android, with PC as a longer-term goal.

## Vision
- Third-person gameplay with a fixed player camera
- A hostile, post-apocalyptic environment to explore
- Zombies that pursue and attack the player
- Weapons, shooting, and enemy health
- Mobile touch controls for movement and firing
- Player health, survival objectives, game-over, and restart
- Future possibilities: missions, boss encounters, and multiplayer

## Development plan
1. Build a small playable browser prototype.
2. Test movement, camera, combat, and performance on Android.
3. Improve the environment, enemies, audio, and survival systems.
4. Evaluate the longer-term path toward a more advanced native Android/PC game.

## Current status
**Early planning stage.** The features above describe the intended direction; they are not yet implemented.

## Technology direction
The initial browser prototype is planned to use JavaScript and Three.js. GitHub is used to manage the project's source code. The final engine and release architecture may change as the project develops.

## Contributing
